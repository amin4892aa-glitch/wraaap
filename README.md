# WRAAAP

Rezeptseite für cremige Puten-Wraps. Mausbewegung hinterlässt Burrito-Emojis, oben läuft der WRAAAAPS-Wellentext.

## Lokal starten

```bash
npm install
npm run dev
```

## Auf Render hosten

1. Dieses Repo auf GitHub verbinden.
2. Neuen **Static Site**-Service anlegen.
3. Build Command: `npm ci && npm run build`
4. Publish Directory: `dist`

Oder das mitgelieferte `render.yaml` beim Blueprint-Deploy nutzen.
