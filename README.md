# WRAAAP

Rezeptseite für cremige Puten-Wraps. Mausbewegung hinterlässt Burrito-Emojis, oben läuft der WRAAAAPS-Wellentext.

## Lokal starten

```bash
npm install
npm run dev
```

## Auf Render hosten

**Web Service** (passt zum aktuellen Setup):

1. Repo `amin4892aa-glitch/wraaap` verbinden
2. Build Command: `npm ci && npm run build`
3. Start Command: `npm start` (serviert `dist` mit `serve`)

Oder Blueprint mit `render.yaml` nutzen.
